# Taskbar Key Indicator (작업표시줄 키보드 연결 인디케이터)

멀티페어링 키보드를 사용하는 Windows PC 환경에서, 웹브라우저 화면을 띄우지 않아도 **현재 키보드가 PC에 유선 연결되어 있는지 모바일(블루투스)로 전환되었는지를 작업표시줄 상단 네온 LED 바로 즉각 시각화**해주는 초경량 백그라운드 유틸리티입니다.

---

## 🌟 개발 배경 및 핵심 특징

- **시인성 문제 극복**: Windows 기본 시스템 트레이는 외부 프로그램 아이콘을 `^` 숨김 영역에 몰아넣어 상태 확인이 불편합니다. 본 프로그램은 **작업표시줄 최상단 테두리에 얇은 3px 네온 LED 라인을 점등**하여 어떤 화면에서도 0.1초 만에 상태를 파악할 수 있습니다.
- **100% 이벤트 드리븐 (0ms 반응 & 0% CPU)**:
  - 무한 루프나 주기적 폴링(Polling) 없이, OS 하드웨어 이벤트(`WM_DEVICECHANGE`)를 0ms 즉각 수신하여 배터리와 CPU 점유율이 완벽하게 0%입니다.
  - 키보드에서 스위치나 단축키로 모바일(BT)로 전환하여 유선 연결이 분리되는 순간 0.001초 만에 LED 바가 켜집니다.
- **클릭 100% 투과 (Click-Through)**:
  - `WS_EX_TRANSPARENT | WS_EX_LAYERED` 기술을 적용하여 시작 버튼, 작업표시줄 앱 아이콘, 시계 등 모든 마우스 클릭 및 제스처가 100% 그대로 통과됩니다. 작업표시줄 사용에 일체의 간섭이나 방해가 없습니다.
- **세련된 하드웨어 LED 스트립 렌더링**:
  - 단순 단색 선이 아닌, 중앙 코어 하이라이트와 은은한 섀도우가 적용된 정교한 네온 LED 효과로 촌스럽지 않고 고급스럽습니다.
- **다중 모니터 완벽 지원**:
  - 주 모니터 작업표시줄(`Shell_TrayWnd`)뿐 아니라 보조 모니터 작업표시줄(`Shell_SecondaryTrayWnd`)까지 모두 감지하여 동일하게 LED 바를 표시합니다.
- **완전 오프라인 & Zero-Dependency**:
  - 단일 실행 파일(`.exe`, 약 530KB) 하나로 구동되며 별도의 .NET이나 Visual C++ 재배포 패키지 설치가 필요 없습니다.
  - 네트워크 통신 패킷 0건 (사내 보안 환경에서도 100% 안전 구동).
  - 관리자 권한 불필요 (일반 사용자 권한 구동).

## 🚀 빠른 시작

1. 이 저장소의 [`dist/`](dist/) 폴더(또는 저장소 ZIP 다운로드)에서 **`TaskbarKeyIndicator.exe`**를 원하는 폴더에 넣고 더블 클릭하여 실행합니다.
2. **동작 방식**:
   - **PC 유선 연결 상태**: 작업표시줄이 평상시 기본 상태를 유지합니다 (소등).
   - **모바일 블루투스 전환 상태**: 작업표시줄 맨 윗단에 선명한 **네온 레드 LED 바**가 즉시 점등됩니다.
   - **PC 유선 복귀 상태**: LED 바가 0ms로 소등되어 본래 작업표시줄로 돌아옵니다.

## ⚙️ 트레이 메뉴 및 설정

작업표시줄 우측 하단 트레이 아이콘을 우클릭하여 다음 설정을 즉시 변경할 수 있습니다:

- **상태 확인**: 현재 감지된 키보드 이름 및 VID/PID 실시간 확인.
- **키보드 타겟 고정**: 여러 개의 키보드가 있을 경우, 현재 연결된 키보드를 감시 타겟으로 즉시 락(Lock).
- **LED 색상 변경**: 네온 레드, 네온 오렌지, 네온 앰버, 네온 핑크, 네온 블루 원터치 전환.
- **LED 두께 설정**: 2px, 3px (기본), 4px, 5px 조절.
- **유선 연결 시에도 초록 LED 표시**: PC 유선 연결 중에도 은은한 초록 네온 바를 유지하고 싶을 때 토글.
- **윈도우 시작 시 자동 실행**: PC 부팅 시 자동 시작 등록/해제.
- **설정 파일 열기**: `config.ini`를 메모장으로 즉시 열람 및 정밀 편집.

## 📄 설정 파일 (`config.ini`)

프로그램 실행 위치에 자동으로 생성되며 메모장으로 언제든 커스텀 가능합니다:

```ini
[Settings]
; 키보드 유선 분리(모바일 전환) 시 작업표시줄 상단 LED 바 색상
DisconnectedColor=#FF2D55

; 키보드 유선 연결 시 LED 바 색상
ConnectedColor=#32D74B

; 유선 연결 시에도 LED 바를 표시할지 여부 (0: 소등[기본], 1: 점등)
ShowWhenConnected=0

; LED 바 두께 (픽셀 단위, 기본: 3)
BarThickness=3

; 자동 감지 모드 (1: 활성[기본], 0: 특정 VID/PID 지정)
AutoDetect=1

; 특정 키보드만 감시하려면 아래에 대문자 4자리 16진수 입력 (선택 사항)
TargetVid=
TargetPid=
TargetDeviceName=
```
