# Taskbar Key Indicator (작업표시줄 키보드 전환 인디케이터)

VDI 및 멀티페어링 키보드 환경에서 웹브라우저 창을 직접 열어두지 않아도 **현재 키보드가 PC에 연결되어 있는지 모바일(블루투스)로 전환되었는지를 작업표시줄 상단 네온 LED 바로 즉각 시각화**해주는 극초경량 백그라운드 유틸리티입니다.

---

## 🌟 핵심 특징

- **시인성 극대화 (작업표시줄 상단 3px 네온 LED 바)**:
  - Windows 트레이의 숨김 영역(`^`)을 확인할 필요 없이, **작업표시줄 최상단 테두리에 얇은 3px 네온 LED 라인이 점등**되어 어떤 전체화면/작업 중에도 0.1초 만에 현재 키보드 상태를 즉각 파악할 수 있습니다.
- **100% 이벤트 드리븐 Win32 훅 (0ms 반응 & CPU 0%)**:
  - 브라우저 탭 타이틀(`[PC]` ↔ `[MB]`) 변화를 Windows OS 이벤트(`SetWinEventHook(EVENT_OBJECT_NAMECHANGE)`)로 가로채어, 브라우저가 최소화되거나 다른 창 뒤에 숨겨져 있어도 0ms 즉각 반응합니다.
  - 무한 루프나 주기적 폴링이 없어 CPU 점유율 및 리소스 사용량이 실질적으로 0%입니다.
- **VDI / 씬클라이언트 완벽 대응**:
  - 로컬 씬클라이언트 USB 장치 신호가 전달되지 않는 폐쇄망/VDI 가상화 환경에서도 100% 안정적으로 동작합니다.
- **클릭 100% 투과 (Click-Through)**:
  - `WS_EX_TRANSPARENT | WS_EX_LAYERED` 기술을 적용하여 시작 버튼, 작업표시줄 앱 아이콘, 시계 등 모든 마우스 클릭 및 제스처가 100% 그대로 통과됩니다. 작업표시줄 사용에 일체의 간섭이 없습니다.
- **다중 모니터 완벽 지원**:
  - 주 모니터 작업표시줄(`Shell_TrayWnd`)뿐 아니라 보조 모니터 작업표시줄(`Shell_SecondaryTrayWnd`)까지 모두 감지하여 동일하게 LED 바를 표시합니다.
- **완전 오프라인 & Zero-Dependency (포터블 단일 exe)**:
  - 단일 실행 파일(`.exe`, 약 528KB) 하나로 구동되며 외부 런타임(.NET, VC++ Redist) 설치가 필요 없습니다.
  - 네트워크 패킷 0바이트, 관리자 권한 불필요.

---

## 🚀 동작 방식

- **PC 연결 상태 (`[PC]` 감지)**:
  - 기본 설정 시 작업표시줄이 평상시 상태를 유지합니다 (옵션 켜짐 시 은은한 네온 그린 점등).
  - 트레이 아이콘: 초록색 LED.
- **모바일 전환 상태 (`[MB]` 감지)**:
  - 작업표시줄 최상단에 선명한 **네온 레드 LED 바**가 0ms 즉시 점등됩니다.
  - 트레이 아이콘: 빨간색 LED.

---

## ⚙️ 트레이 메뉴 및 설정

작업표시줄 우측 하단 트레이 아이콘을 우클릭하여 다음 설정을 즉시 변경할 수 있습니다:

- **상태 확인**: 현재 연결 상태 (`PC 연결됨` / `모바일 전환됨`) 및 동기화 탭 제목 표시.
- **⚡ LED 바 강제 테스트**: 5초간 네온 LED 바를 강제 점등하여 디스플레이 위치/두께 테스트.
- **📋 실시간 로그 열기**: 동작 내역 및 디버그 로그(`debug.log`) 확인.
- **LED 바 색상 설정**: 네온 레드, 네온 오렌지, 네온 앰버, 네온 핑크, 네온 블루 원터치 전환.
- **LED 바 두께 설정**: 2px, 3px (기본/권장), 4px, 5px 조절.
- **유선 연결 시에도 초록 LED 표시**: PC 작업 중에도 작업표시줄 상단에 초록 네온 바를 유지할지 여부 토글.
- **윈도우 시작 시 자동 실행**: PC 부팅 시 자동 시작 레지스트리 등록/해제.
- **설정 파일 열기**: `config.ini`를 메모장으로 즉시 열람 및 편집.

## 📄 설정 파일 (`config.ini`)

프로그램 실행 위치에 자동으로 생성되며 메모장으로 언제든 커스텀 가능합니다:

```ini
[Settings]
; 키보드 모바일 전환 시 작업표시줄 상단 LED 바 색상
DisconnectedColor=#FF2D55

; 키보드 PC 연결 시 LED 바 색상
ConnectedColor=#32D74B

; PC 연결 시에도 LED 바를 표시할지 여부 (0: 소등[기본], 1: 점등)
ShowWhenConnected=0

; LED 바 두께 (픽셀 단위, 기본: 3)
BarThickness=3
```

## 🛠️ 빌드 방법 (개발자용)

Linux / WSL2 환경에서 `zig c++`를 통해 Windows x86_64 바이너리로 크로스 컴파일:

```bash
chmod +x build.sh
./build.sh
```

- 빌드 산출물: `dist/TaskbarKeyIndicator.exe` (약 528KB)
